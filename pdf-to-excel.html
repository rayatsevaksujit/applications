PDF निवडा आणि रूपांतरण सुरू करा. वापरण्यापूर्वी Python backend चालू असणे आवश्यक आहे.

Google Cloud Vision वापरण्यासाठी Google Cloud मध्ये Vision API सुरू करून API key तयार करा आणि Render → Environment मध्ये GOOGLE_CLOUD_VISION_API_KEY नावाने key सुरक्षितपणे जोडा. Key वेबसाइटच्या HTML किंवा GitHub मध्ये टाकू नका. Google OCR निवडल्यास PDF पानांची चित्रे Google कडे पाठवली जातात; Google Cloud शुल्क लागू होऊ शकते.

ही सेवा Render वर चालते. Free instance निष्क्रियतेनंतर झोपेत जाऊ शकते, त्यामुळे पहिल्या रूपांतरणाला थोडा वेळ लागू शकतो. PDF मधील टेबलची मांडणी आणि OCR अचूकता मूळ फाइलच्या गुणवत्तेवर अवलंबून असते.
